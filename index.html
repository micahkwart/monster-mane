🎮 Monster Mane

Epic 3D Local Multiplayer Fighting Game

About the Game

Monster Mane is an action-packed 3D fighting game built with Python and the Ursina engine. Battle your friend in an epic arena showdown where two cube warriors fight to the finish!

Features

🥊 Two Player Combat

Local multiplayer on one keyboard - Red vs Blue cube fighters!

❤️ Health System

Visual health bars and damage tracking. Fight until the last HP!

⚡ Attack System

Range-based attacks with cooldown and visual feedback.

🌍 3D Physics

Gravity simulation and ground collision in a 3D arena.

🎯 Win Condition

Game Over screen when health reaches zero.

🔄 Restart Button

Quick restart to jump back into the action!

Controls

🔴 Player 1 (Red)

Move Forward W
Move Backward S
Move Left A
Move Right D
Attack F

🔵 Player 2 (Blue)

Move Forward ↑
Move Backward ↓
Move Left ←
Move Right →
Attack M

How to Install & Play

  • Download the game
    Click one of the download buttons above to get the game files.
  • Extract the files
    Unzip the downloaded file to a folder on your computer.
  • Install Python
    Make sure you have Python 3.12 or higher installed from python.org
  • Easy Launch
    Windows: Double-click launch_game.bat
    Mac/Linux: Double-click launch_game.sh
    The launcher will automatically install dependencies and start the game!
  • Optional: Desktop Shortcut
    Run the shortcut creation script for your OS:
    • Windows: create_shortcut_windows.bat
    • Linux: create_shortcut_linux.sh
    • Mac: create_shortcut_mac.sh

Manual Installation (Advanced)

If you prefer to run from the command line:

# Install dependencies
pip install -r requirements.txt

# Run the game
python fighting_game.py

System Requirements

  • Python 3.12 or higher
  • Windows, macOS, or Linux
  • Graphics card with OpenGL support
  • Keyboard (for 2-player local multiplayer)
  • ~100MB free disk space
